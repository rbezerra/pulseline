# Vendor-Agnostic AI Triage Port and Standardized 768-Dimension Vectors

To avoid vendor lock-in while using LLM tool calling, structured outputs, and `pgvector` semantic search, the BFF abstracts model interactions behind a domain port implemented with the Vercel AI SDK (`gemini`, `openai`, `ollama`, and an offline `mock` provider) and standardizes `pgvector` columns on `vector(768)`. Because `pgvector` requires fixed column dimensions at index creation time, `768` is chosen as the canonical dimension supported natively by Gemini (`text-embedding-004`) and Ollama (`nomic-embed-text`) and via Matryoshka dimension reduction (`dimensions: 768`) on OpenAI (`text-embedding-3-small`), allowing provider changes via configuration without schema migrations (requiring only runbook re-embedding when switching latent spaces).
